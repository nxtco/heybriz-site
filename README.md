# heybriz-site

Source for the heybriz landing page at **https://www.heybriz.com**.

Static HTML, no build step. Deployed by Vercel on every push to `main`.

- `index.html` — landing page
- `privacy.html` — privacy policy, served at `/privacy` (`cleanUrls`)

The desktop app installer is published as a GitHub Release in
[nxtco/heybriz-releases](https://github.com/nxtco/heybriz-releases/releases/latest).
The application source is kept in a private repository.
